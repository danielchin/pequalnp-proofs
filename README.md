# pequalnp-proofs PR Relay Branch (`pr-bot`)

This orphan branch holds a GitHub Actions workflow that automatically opens pull requests on `open-goat/pequalnp-proofs` whenever a verified proof request file is pushed to `requests/<gap-id>.json`.

It is completely separate from `main` and from all `L-*` proof branches so proof PR diffs remain single-file and identical to `upstream/main`.
